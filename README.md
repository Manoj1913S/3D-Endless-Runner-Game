# Chaos Run 

Chaos Run is a 3D endless runner game made with Unity 6.3 LTS and C#. The player runs through an endless road, avoids obstacles, and collects coins.
##  Features

* Procedural generation of an endless road
* Player movement and jumping
* Coin collection and score system
* Obstacles and collision detection
* Player animations
* Sound and audio system
* Third-person camera using Cinemachine
* Cinemachine Composer for camera framing
* 3D environment and lighting

##  Built With

* Unity 6.3 LTS
* C#
* Cinemachine
* Unity Animator
* Unity Audio System

## What I Learned

* Procedural generation of an endless road
* Player movement and input handling
* C# Lists and managing game objects
* Dependency Injection in Unity
* Collision detection and trigger events
* Animation states and transitions
* Cinemachine camera setup and composition
* Sound effects and audio management
* Score and coin collection systems
* Creating a 3D game environment

##  How to Run
1. Clone or download this repository.
2. Open the project in Unity Hub.
3. Open the `MainLevel` scene.
4. Press Play to start the game.

##  About This Project

This project helped me improve my Unity and C# skills by building a 3D endless runner from scratch.
It was a great learning experience in procedural generation, game mechanics, camera systems, animations, and audio.
